# Mouana x Luxtech

Коллаб-проект Mouana и Luxtech. Стек: Astro + TypeScript (strict), без React.

## Структура

```
src/
├── layouts/
│   └── Layout.astro   — базовый HTML-каркас страницы
└── pages/
    └── index.astro    — главная страница
```

## Команды

| Команда           | Действие                                  |
| ------------------ | ------------------------------------------ |
| `npm install`      | Установка зависимостей                     |
| `npm run dev`       | Локальный dev-сервер, http://localhost:4321 |
| `npm run build`     | Сборка в `./dist/`                          |
| `npm run preview`   | Просмотр собранной версии                   |
| `npm run astro ...` | Astro CLI (`astro add`, `astro check`)      |
